Как импортировать конфигурацию и начать пользоваться прокси.

Подписка на конфигурацию — рекомендуемый способ

Подписка автоматически обновляет профили и настройки с сервера. Для браузера и Android используйте:

  • Основной URL: https://pxc-ru.jethelix.ru/api/config.
  • Резервный URL: https://pxc-kz.jethelix.ru/api/config.
  • Авторизация Basic Auth: ваш логин и пароль PX Manager.
  • Интервал проверки: 60 минут; автоматическое обновление включено.

При недоступности основного источника клиент попробует резервный. Если оба недоступны, сохраняется последняя рабочая конфигурация. Используйте HTTPS-адреса без изменений: перенаправления не поддерживаются.

Chrome и Firefox — BrowserMegaProxy

  1. Установите BrowserMegaProxy по инструкции проекта, выбрав версию для Chrome или Firefox.
  2. Для Firefox разрешите расширению работу в приватных окнах в about:addons: это необходимо для управления прокси.
  3. Через кнопку расширения откройте настройки MegaProxy, затем импорт конфигурации по URL.
  4. Укажите основной URL и реквизиты Basic Auth из раздела выше, включите Подписаться на обновления конфигурации.
  5. Скачайте конфигурацию, проверьте изменения и подтвердите импорт. В разделе Подписка на конфигурацию проверьте резервный URL, интервал 60 минут и автоматическое обновление; сохраните подписку.
  6. Выберите профиль в окне расширения и включите режим Proxy. Импорт сам по себе не включает подключение.

Для ручного обновления нажмите Обновить сейчас в настройках или окне расширения.

Android — AndroidMegaProxy

  1. Установите AndroidMegaProxy по инструкции проекта.
  2. Откройте Настройки → Подписка на конфигурацию.
  3. Укажите основной и резервный URL из раздела выше, включите Basic Auth и введите свой логин и пароль PX Manager.
  4. Задайте интервал 60 минут, включите автоматическое обновление и сохраните подписку.
  5. Нажмите Обновить сейчас, дождитесь успешного обновления и выберите нужный профиль.
  6. Запустите подключение и разрешите VPN, когда Android запросит разрешение.

Android может откладывать фоновые обновления из-за ограничений батареи и сети. Если после обновления приложение предлагает переподключиться, переподключите VPN.

Запасной способ — импорт MegaProxy JSON

  1. На главной странице PX Manager нажмите MegaProxy и скачайте JSON-файл.
  2. В BrowserMegaProxy или AndroidMegaProxy откройте импорт конфигурации из файла, выберите скачанный JSON и подтвердите импорт.
  3. Если файл содержит подписку, проверьте её параметры: дальнейшие обновления будут приходить автоматически. Если подписки нет, для обновления скачайте и импортируйте свежий файл.
  4. Повторный импорт обновляет профили с теми же ID без дублирования. Если клиент предложит удалить отсутствующие профили, отметьте только устаревшие.
  5. Выберите профиль и включите подключение.

Файл может содержать пароли: храните его приватно и не пересылайте другим пользователям.

Shadowrocket для iOS

  1. Установите Shadowrocket из App Store.
  2. Вернитесь в PX Manager и скачайте Shadowrocket.conf.
  3. Откройте Shadowrocket и нажмите + в правом верхнем углу.
  4. Выберите Import from File и укажите скачанный файл Shadowrocket.conf.
  5. Проверьте импортированные настройки и подтвердите импорт.
  6. Выберите группу PROXY, затем выберите нужный прокси из импортированного списка серверов.
  7. Включите главный переключатель подключения.
  8. Если iOS попросит разрешить VPN-конфигурацию, нажмите Разрешить и подтвердите действие код-паролем или Face ID.
  9. Для проверки откройте сайт проверки IP-адреса в Safari и убедитесь, что отображается IP выбранного прокси.

Если не работает

  • Если подписка не обновляется, проверьте URL и реквизиты Basic Auth, затем нажмите Обновить сейчас. При ошибке 403 проверьте логин и пароль.
  • Если импорт не прошёл, скачайте конфиг заново и повторите импорт со свежим файлом.
  • Если прокси не подключается, попробуйте другой импортированный профиль из того же списка.
  • Если трафик браузера не меняется, проверьте, что в MegaProxy выбран нужный профиль и режим Proxy.
  • Если Shadowrocket не видит файл, откройте приложение Файлы, найдите Shadowrocket.conf в Загрузках и отправьте его в Shadowrocket через меню Поделиться.
