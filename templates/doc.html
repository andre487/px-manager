Документация

MegaProxy для Android

  1. Установите MegaProxy.
  2. Вернитесь в PX Manager и скачайте MegaProxy.json.
  3. Откройте настройки профилей MegaProxy и выберите импорт конфигурации из JSON.
  4. Укажите скачанный файл и подтвердите импорт.
  5. При повторном импорте существующие профили обновятся, а новые добавятся без дублирования.
  6. Если MegaProxy предложит удалить отсутствующие профили, отметьте только действительно устаревшие.
  7. Выберите нужный профиль и запустите подключение.
  8. Если Android запросит разрешение VPN, разрешите его.

Браузерное расширение FoxyProxy

  1. Установите FoxyProxy Standard из магазина расширений вашего браузера.
  2. Вернитесь в PX Manager и скачайте FoxyProxy.json.
  3. Откройте настройки расширения FoxyProxy.
  4. Откройте раздел Import, выберите импорт из локального файла и укажите скачанный JSON-файл.
  5. Сохраните импортированные настройки, если FoxyProxy попросит подтверждение.
  6. Через кнопку FoxyProxy на панели браузера выберите импортированный профиль прокси.

Super Proxy для Android

  1. Установите Super Proxy из Google Play.
  2. Вернитесь в PX Manager и скачайте SuperProxy.txt.
  3. Откройте Super Proxy и используйте импорт списка прокси.
  4. Выберите скачанный файл SuperProxy.txt.
  5. Выберите импортированный профиль прокси и запустите подключение.
  6. Если Android запросит разрешение VPN, разрешите его: так Super Proxy сможет направлять трафик приложений через выбранный прокси.

Shadowrocket для iOS

  1. Установите Shadowrocket из App Store.
  2. Вернитесь в PX Manager и скачайте Shadowrocket.conf.
  3. Откройте Shadowrocket и нажмите + в правом верхнем углу.
  4. Выберите Import from File и укажите скачанный файл Shadowrocket.conf.
  5. Проверьте импортированные настройки и подтвердите импорт.
  6. Выберите группу PROXY, затем выберите нужный прокси из импортированного списка серверов.
  7. Включите главный переключатель подключения.
  8. Если iOS попросит разрешить VPN-конфигурацию, нажмите Разрешить и подтвердите действие код-паролем или Face ID.
  9. Для проверки откройте сайт проверки IP-адреса в Safari и убедитесь, что отображается IP выбранного прокси.

Если не работает

  • Если импорт не прошёл, скачайте конфиг заново и повторите импорт со свежим файлом.
  • Если прокси не подключается, попробуйте другой импортированный профиль из того же списка.
  • Если трафик браузера не меняется, проверьте, что FoxyProxy включён и выбран импортированный профиль.
  • Если Shadowrocket не видит файл, откройте приложение Файлы, найдите Shadowrocket.conf в Загрузках и отправьте его в Shadowrocket через меню Поделиться.
